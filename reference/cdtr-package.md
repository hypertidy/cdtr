# cdtr: Constrained Delaunay Triangulation with Refinement via CDT

Binding to the artem-ogre/CDT header-only C++ library (MPL-2.0):
constrained and conforming Delaunay triangulation, Ruppert refinement by
area or minimum angle, resolution of crossing constraints, and
topological region depth per triangle. Aimed at replacing RTriangle in
anglr.
